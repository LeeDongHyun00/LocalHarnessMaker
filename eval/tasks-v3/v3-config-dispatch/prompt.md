Refactor directives.Parser.parse to dispatch through registered handlers instead of a directive-name conditional ladder. Keep Parser(), register(name, handler), parse(text, initial=None), and the per-instance handlers mapping public.
CD1. Parse str.splitlines() in source order with one-based line numbers. Strip each line's outer whitespace; skip blank lines and lines starting with #. Split the first whitespace-delimited word as the case-sensitive directive name; the remainder is the argument with outer whitespace removed and interior whitespace retained. Unknown names raise ValueError('line N: unknown NAME') at that line and stop processing. A # inside an argument is literal, not an inline comment.
CD2. Built-in set KEY VALUE sets a string, append KEY VALUE joins an existing string and VALUE with one comma (or stores VALUE if absent), and unset KEY removes a key if present. set/append require a key and nonempty value, split on the first whitespace run; unset requires exactly one word. Invalid arguments raise ValueError('line N: argument'). Copy initial into a fresh dict; never mutate initial. Empty input returns that copy.
CD3. Every directive, including all built-ins, must look up its handler in self.handlers at dispatch time. register accepts a nonempty lowercase ASCII letter-only name, rejects invalid names with ValueError('invalid directive'), and rejects an already registered name with ValueError('duplicate directive: NAME'). Do not alter the registry on rejection. A handler receives (mutable_state, argument, line_number), mutates state, and its return is ignored. Handler exceptions propagate unchanged and stop parsing. New registrations and direct handler replacements take effect on the next line dispatch.
CD4. Preserve entry-point signatures and keep parser instances and successive parse calls independent. Add tests for a custom extension, built-in replacement, diagnostic order and source-order side effects.
