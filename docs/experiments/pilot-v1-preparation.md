# 파일럿 v1 준비 보고서

작성 기준: 2026-10-14, Asia/Seoul. 단계 0의 입력·정책 준비 기록이며 개발 성능 보고서가 아닙니다.

## 이번 작업

- 프론트엔드와 백엔드 프로젝트의 요구사항 원본을 준비했습니다.
- 각 원본에 요구사항별 판정 시나리오, 핵심 기능 표시, 사용자 답변과 수정 요청을 연결했습니다.
- A~E 최초 요청과 동일한 공통 시작 자료를 준비했습니다.
- 질문·수정·제출·블라인드 평가 정책을 [policies.json](../../experiments/pilot-v1/policies.json)에 정리했습니다.
- 구조와 체크섬을 확인하는 [검증 스크립트](../../scripts/validate_pilot.py)를 추가했습니다.

## 실제 교사 호출

`codex exec`에서 `gpt-6.1-sol`을 명시하는 경로를 사용했습니다. 최초 시도는 기존 ChatGPT 로그인 토큰 갱신 오류로 실패했습니다. 사용자가 기기 인증으로 로그인한 뒤 요구사항 생성 호출이 성공했습니다.

요구사항과 A~E 요청 생성 호출 2회가 성공했습니다. 성공 호출의 합계 사용량은 입력 36,550토큰, 출력 11,222토큰입니다. 별도 보고된 추론 출력 123토큰은 출력 합계에 다시 더하지 않습니다. 이는 연구용 생성 사용량이며 실제 개발 실행 비용이 아닙니다.

정확한 작업·사용량과 원본 해시는 [provenance.json](../../experiments/pilot-v1/provenance.json)에 기록합니다. CLI 모델 선택과 성공을 근거로 하며 서버의 불변 모델 스냅샷 ID가 별도로 노출됐다고 주장하지 않습니다. 금액 과금과 구독 사용량을 같은 것으로 가정하지 않습니다.

## 프로젝트와 평가 범위

| 프로젝트 | 핵심 동작 | 판정 범위 |
| --- | --- | --- |
| 가정 식재료 소비 일정판 | 등록·수량 소비·기준일과 기한 필터 | 필수 요구사항 7개, 브라우저 시나리오 15개 |
| 공유 작업실 장비 예약 API | 장비·예약 생성·시간 충돌 방지 | 필수 요구사항 7개, 순차 HTTP·정상 재시작 시나리오 15개 |

백엔드의 동시 요청 경쟁과 비정상 종료 복구는 이번 원본에서 범위 밖입니다. 프론트엔드의 스타일·DOM 선택자와 백엔드의 특정 프레임워크는 평가 정답이 아닙니다. 시나리오의 e1·e2·r1은 실제 생성 id의 별칭으로 사용합니다.

## 생성 자료 검토에서 발견한 문제

교사 원본의 30개 시나리오에서 기대 결과가 `when`의 `(Then)` 뒤에 들어가고 `then`은 비어 있었습니다. 명시된 기대 결과를 내용 변경 없이 `then`으로 분리했습니다. 스키마에도 빈 단계가 허용되지 않도록 `minLength`를 추가했습니다.

백엔드 B6의 종료 시각 설명은 종료와 시작이 같은 입력도 거절하는 기존 시나리오와 일치하도록 `종료 <= 시작`으로 명확히 했습니다. 보정 전 원본과 보정 내역은 각각 [교사 원본](../../experiments/pilot-v1/authoring/teacher-intent-cards.original.json), [검토 기록](../../experiments/pilot-v1/authoring/intent-review.json)에 보존했습니다.

이 작업은 요구사항 원본의 형식·일관성 검토입니다. 앱의 실제 기능, 프롬프트 효과나 교사 모델의 개발 성능을 평가한 결과가 아닙니다.

A/B의 정보 보존과 C/D의 목표 일치를 작업 에이전트가 문장 단위로 검토했습니다. E는 C 원문과 기술 후보 문단의 접합을 자동 확인했습니다. E에는 기술과 구현 안내가 함께 있으므로 향후 E/C 차이를 특정 라이브러리의 단독 효과로 해석하지 않습니다.

브라우저 환경은 Chromium 151.0.7922.34 실행, 기본 화면과 접근성 locator, Asia/Seoul 시간대 설정까지 확인했습니다. 실제 식재료 앱을 실행하거나 판정한 확인은 아닙니다.

## 준비와 실행의 구분

현재 자료는 학습 정답으로 채택하지 않았고 개발 실험은 아직 실행하지 않았습니다. [runtime.json](../../experiments/pilot-v1/runtime.json)에 프로토콜 고정 전 남은 항목을 표시합니다.

규모와 한도 후보는 2프로젝트 × 5군 × 2반복, 질문·수정 각각 최대 3왕복, 첫 제출 600초·전체 실행 1200초입니다. 이는 검토할 초안이며 확정된 실행 기록이 아닙니다. 실제 비용·사용량 한도와 평가 지표 기준 수치, 평가 담당자는 아직 정해야 합니다.

4. 실행 한도·사용량·평가 담당자를 정하고 프로토콜을 고정합니다.
