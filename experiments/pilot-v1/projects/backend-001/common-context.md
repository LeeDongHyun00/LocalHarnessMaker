Linux, Node.js 24, Python 3.12가 제공된다. 외부 계정, 유료 서비스, 비밀 키 없이 실행 가능한 새 프로젝트를 작성하고 실행 명령과 접근 주소를 설명하는 안내를 제공한다. HTTP 서버는 0.0.0.0에 바인딩하고 PORT 환경변수를 지원하며 기본 포트는 3000이다. 요청과 응답 본문은 JSON이다. 공통 경로 계약은 POST /equipment 요청 {name}, GET /equipment 응답 배열, POST /reservations 요청 {equipment_id, borrower, start_at, end_at}, GET /reservations 응답 배열 및 선택적 equipment_id·status 쿼리, POST /reservations/{id}/cancel이다. 장비 객체 필드는 id와 name이며 예약 객체 필드는 id, equipment_id, borrower, start_at, end_at, status다. 생성 응답은 해당 객체다. id와 equipment_id는 문자열이다. 시간 입력은 YYYY-MM-DDTHH:mm:ssZ 형식이다. 오류 응답 형식은 {error: {code, message}}이며 두 값은 문자열이다. 업무 동작, 상태값, HTTP 상태 코드와 오류 정책은 개별 요구사항에서 정한다.

공통 실행·제출 계약: 루트 run.json에 start_command(문자열 배열)와 ready_url을 기록하고 README에 의존성 설치 및 시작 명령을 적습니다. start_command는 이미 설치한 의존성으로 서비스를 시작하는 명령입니다. PORT로 전달한 포트를 사용하며 기본 포트는 공통 맥락의 3000입니다. ready_url은 GET /equipment입니다. 기존 API 경로 외에 health 경로를 추가할 의무는 없습니다. 명시하지 않은 요구사항 중 구현 결과를 크게 바꾸는 사항은 질문할 수 있습니다. 질문만 한 턴은 완료 제출이 아닙니다. 구현 완료 시 실행 안내와 결과를 제출합니다.
