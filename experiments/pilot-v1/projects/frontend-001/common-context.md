Linux, Node.js 24, Python 3.12가 제공된다. 외부 계정, 유료 서비스, 비밀 키 없이 실행 가능한 새 프로젝트를 작성하고 실행 명령과 접근 주소를 설명하는 안내를 제공한다. 개발 서버는 0.0.0.0에 바인딩하고 PORT 환경변수를 지원하며 기본 포트는 3000이다. 브라우저의 / 경로에서 앱에 접근한다. 평가에 사용하는 식재료 정보의 이름은 이름, 수량, 소비기한이며, 날짜 입력 형식은 YYYY-MM-DD이다. 특정 프레임워크, DOM 선택자, 화면 스타일은 계약에 포함하지 않는다.

공통 실행·제출 계약: 루트 run.json에 start_command(문자열 배열)와 ready_url을 기록하고 README에 의존성 설치 및 시작 명령을 적습니다. start_command는 이미 설치한 의존성으로 서비스를 시작하는 명령입니다. PORT로 전달한 포트를 사용하며 기본 포트는 공통 맥락의 3000입니다. ready_url은 / 페이지입니다. 명시하지 않은 요구사항 중 구현 결과를 크게 바꾸는 사항은 질문할 수 있습니다. 질문만 한 턴은 완료 제출이 아닙니다. 구현 완료 시 실행 안내와 결과를 제출합니다.
